Tái cấu trúc package model & Sửa lỗi phân trang sản phẩm ẩn

[Chi tiết thay đổi phía App (Client)]:
- Tách tất cả các inner class của model gốc thành các file độc lập.
- Tổ chức lại cấu trúc package:
  + com.example.storehub.model.request: Chứa LoginRequest, RegisterRequest, AddToCartRequest, UpdateQuantityRequest, CancelOrderRequest, UpdateStatusRequest, AddReviewRequest, ReplyReviewRequest.
  + com.example.storehub.model.response: Chứa Response, LoginResponse, DashboardData, RevenueData, TopProduct, RecentActivity, DailyStat, TimelineStep.
  + com.example.storehub.model: Giữ lại các bảng thực thể chính User, Product, Order, CartItem, News, Pagination cùng các embedded entities ProductColor, ProductReview.
- Xóa các file thừa AdminStats.java và Response.java cũ.
- Sửa đổi import bị lỗi trên toàn bộ dự án (~30 file liên quan).
- Giải quyết xung đột tên lớp RecentActivity (Model và Activity) bằng FQCN.
- Thêm chú thích mô tả ý nghĩa cho từng trường dữ liệu trong các file Request/Response DTO chưa có comment.
- Cập nhật ApiServices.java và các fragment/activity để truyền thêm tham số trạng thái status: khách hàng chỉ lấy sản phẩm "active", admin lấy toàn bộ sản phẩm "".
- Đồng bộ các cập nhật lấy BASE_URL từ remote origin/dev (f4b1073) vào Product, User và ImageUtils.
